# Changelog

## 2.0.0 (2026-10-12)

The analysis was corrected and turned into a tested package. The details and before/after numbers are in [`docs/method-changes.md`](docs/method-changes.md).

### Fixed
- **Sample:** countries are now selected by ISO3 code against the list of UN member states plus Palestine (182 countries). Previously, four World Bank aggregates and ten territories and other non-member entities were included, and Trinidad and Tobago was excluded.
- **Period labels:** the labels now match the non-overlapping years used in the code (1990–2000, 2001–2010, 2011–2023).
- **PPI:** the index is rescaled to 0–100 on one pooled scale instead of separately for each period, so values are comparable across periods.
- **Clusters:** one k-means model is fitted to all periods, so transitions reflect real change rather than relabelling. Clusters are named from their centres.
- **GDP:** log GDP per capita is now used in both the clustering and the regression, matching the published label.
- **Interactive chart:** it now loads data generated by the pipeline (all clustered countries) instead of an embedded extract.

### Added
- `ppi_pathways` package with a command-line pipeline (`python -m ppi_pathways`)
- Tests, linting and continuous integration that reruns the full analysis and checks results are unchanged
- Results as CSV files alongside the workbook, so changes show up line by line in git diffs
- Data documentation (`data/README.md`) and a sovereign-state reference list
